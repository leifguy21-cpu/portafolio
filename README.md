# Portafolio de Leif Flórez · SACOI-Q

HTML, CSS y JS puros, sin build. Los proyectos salen de la carpeta `proyectos/` (ver `proyectos/LEEME.md`).

- **Ver en local:** `node generar-lista.mjs` y luego `npx serve .`
- **Editar textos** (presentación, sobre mí, contacto): `index.html`, en los bloques marcados `EDITAR`.
- **Publicar:** subir a un repo de GitHub, ir a *Settings → Pages → Source: GitHub Actions*. Cada push a `main` publica.
